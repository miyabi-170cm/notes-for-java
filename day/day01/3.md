## [3.无重复最长字符串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/description/)

**难度**：中等　**状态**：✅ 已AC

### 题目
给定一个字符串` s `，请你找出其中不含有重复字符的 最长 子串 的长度。


### 解题思路
- 遍历每一个字符，算出最长；用双指针，l为字符的头，r为尾，向后遍历直到重复，重复即为某一个字符开头最长字串，哈希表去除开头的，l++，从下个字符开始继续

### 解法代码 (Java)
```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Set <Character> set =new HashSet<>();
        char [] a=s.toCharArray();
        int res=0;
        for(int l=0,r=0;r<s.length;r++)
        {
           while(set.contains(a[r]))
            {
                set.remove(a[l]);
                l++;
            }
            set.add(a[r]);
            res=Math.max(res,l-r+1);
        }
        return res;
    }
}
```

### 复杂度
- 时间：O(n)　空间：O(n)

### 思考
- 重复出现时，不一定为开头，可能在中间，但这个长度小于res，直接跳下一个字符
